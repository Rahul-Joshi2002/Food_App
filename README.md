# 🍔 Food_App - Full Stack Food Ordering Platform

A complete Full-Stack Food Ordering Application built using **MERN Stack** (MongoDB, Express.js, React, Node.js) with **Vite** for fast frontend development. The platform consists of two distinct services:

- **User Service**: Food ordering interface for customers.
- **Admin Dashboard**: Interface for managing dishes, tracking orders, and updating order status.

## 🚀 Services Live At

- **User App:** [https://food-user-render-url](https://food-app-frontend-k4tp.onrender.com)  
- **Admin Dashboard:** [https://food-admin-render-url](https://food-app-admin-gn2s.onrender.com/orders)

## ✨ Features

### User Service
- Browse available food items 🍕🍔🥗
- Add items to cart 🛒
- Place orders with real-time status updates ✅

### Admin Dashboard
- View, add, update, and delete dishes 🍽️
- Track incoming orders in real-time 📦
- Change order status (e.g., Preparing, Out for Delivery, Delivered) 🔄
